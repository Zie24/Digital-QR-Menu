# 🍽️ Digital QR Menu

A modern and responsive Digital QR Menu website for restaurants, built using HTML, CSS, JavaScript, and Bootstrap.

## ✨ Features

- Responsive design for all devices
- Modern and attractive user interface
- Food categories
- Search functionality
- QR Code integration
- Smooth scrolling
- Customer reviews section
- Restaurant information
- Fast loading performance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
